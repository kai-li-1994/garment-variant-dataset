# A harmonized fast-fashion garment-variant dataset for textile circularity and sustainability assessment

[![DOI](https://zenodo.org/badge/DOI/10.5281%2Fzenodo.20006389.svg)](https://doi.org/10.5281/zenodo.20006389)

This repository accompanies a public garment-variant dataset for textile circularity and sustainability assessment. It provides the workflow files needed to understand how the archived dataset was produced: Python scripts, mapping tables, processing summaries, a workflow figure, citation metadata, and license files.

The full dataset is archived on Zenodo:

```text
https://doi.org/10.5281/zenodo.20006389
```

The final public data file is:

```text
6_JSONL_component_normalized_public.jsonl
```

It contains 47,522 colour-specific garment-variant records derived from public H&M and Uniqlo product pages for the United Kingdom and Australia. For the full dataset description, field definitions, construction workflow, limitations, and reuse context, please refer to the associated Data in Brief article.

## Repository contents

This repository is intended as a lightweight navigation point for the dataset release. The main file groups are:

- numbered Python scripts used in dataset construction;
- CSV mapping tables for material, category, and component normalization;
- TXT processing summaries reporting row counts and filtering outcomes;
- workflow figure files in PNG and SVG formats;
- citation metadata;
- software and data license files.

The GitHub repository does not track the final JSONL dataset directly because of file-size constraints. Please download the archived dataset from Zenodo.

## Dataset access

Download the dataset and archived release package from Zenodo:

```text
https://doi.org/10.5281/zenodo.20006389
```

The public release focuses on the processed research dataset and documentation needed for reuse. It does not redistribute product images, screenshots, raw HTML, full webpage captures, review text, product ratings, review counts, direct image URLs, or retailer-specific acquisition scripts.

## Suggested reuse

The dataset can support research on garment-level material composition, textile sorting, pre-processing, fibre-to-fibre recycling, design-for-recycling assessment, material-flow modelling, and sustainability-oriented analysis of retailer-disclosed product information.
